## Findings
1. MAJOR fixed - no sex filter. Added `lrgSceneSexOk`, `lrgNormSexes`; `lrgSceneOptions(..., $sexes = null, $furniture = null)`, `lrgPickStartScene($sexes = null, $furniture = null)`. Slot need = action requirements (penis/testicles -> male, vagina -> female, both -> never) and, while `scene_index.intended_sex_only` (default true), intendedSex. Multiset match, unknown participant sex = wildcard, accepts 'male'/'female', m/f or game 0/1. null = old behaviour. Transitions on the route are checked too (OStim skips unfulfilled navigations).
2. MAJOR fixed - action aliases were not resolved, so config exclusions silently missed: scenes use `vampirebite`, `ticklingfeet`; definitions are `vampirebiting`, `ticklingfoot`. 5 vampire-bite scenes (3 tiered "sensual") + 5 "drained" aftermath idles + their transitions were offerable. Actions are now canonicalised through the `aliases` of the action files; config patterns widened. Excluded 14 -> 38: adds vampire bite/drained/devour family (19), FaceFuck/MouthFuck (3), FaceSitting/FaceRiding (2). Ordinary positions untouched.
3. MAJOR fixed - tiers. Unknown-but-gentle actions fell into the conservative "sexual" default: OStim2PStandingKissMF (OStim's main kiss: kissing+holdinghip/head/body), OStim2PStandingCuddleHoldingHeadMF, 4 sleeping/spooning-sleep scenes (afterglow material), 7 holdingleg idles, 6 mounting idles. New `sensual_patterns` (grop*, mounting, teasing, lickingear, holdingleg, holdingthigh, undress_*), `holding*` + `sleeping` as affection, full undress no longer neutral (head/foot item only). Positional idles with no actions (DoggyIdle, FemaleAllFours, SpreadLegsFemale, StandingKneeling ... ~60 scenes) were "neutral" and therefore passed a gentle cap; new `sensual_actor_tags` makes them sensual. No scene tiered below sexual contains a sexual-tagged action (rule guarantees it; only neutral_actions are skipped and none of them is sexual). The 20+ OARE no-action cuddle scenes are affection via the `cuddling` tag - correct. Tiers now: neutral 169, affection 90, kissing 33, sensual 83, sexual 232.
4. MINOR fixed - path-finding: transitions are folded (cost no hop, never offered) like OStim's own route counting; hop-1 scenes OStim's live list rejects are no longer routed through; live match also accepts the transition id used. The game caps `next=` at 24 ids / 700 chars, so a full list is treated as truncated and not authoritative (before, a big hub would have lost valid options). Furniture filter added (`lrgSceneFurnitureOk`, `lrgFurnitureChain`). Gentle graph from the start scene under a kissing cap: 45 scenes (MF) / 34 (FF) / 33 (MM), 21-23 cuddle scenes, all lead back.
5. Added `lrgPickAfterglowScene($current, $liveReachable, $sexes = null, $furniture = null)`: nearest cuddle/embrace (affection..kissing tier, `afterglow_patterns`), up to `afterglow_max_hops` 4 (= game NavigateTo reach), prefers same posture; '' if none or already cuddling.
6. MINOR fixed - robustness: wrong mo2.root logged a warning on EVERY request -> now once an hour (is_file on absent path costs ~1 ms); signature check costs ~12 ms through WSL -> now at most once a minute (`data/.index_checked`); cached index carries a format version; JSON BOM / comments / trailing commas tolerated (`lrgJsonDecodeLoose`; 0 such files today); `glob()` replaced by scandir because MO2 mod folder names with [ ] break glob silently; CRLF modlist lines trimmed; index written with LOCK_EX. Duplicate ids across packs: 0 today, highest MO2 priority wins; ids are case-insensitive keys.
7. MINOR fixed - two options could carry the same label (OARE reuses the display name "Gentle Embrace" for OARE_HoldingChin); duplicates fall back to the readable id.
