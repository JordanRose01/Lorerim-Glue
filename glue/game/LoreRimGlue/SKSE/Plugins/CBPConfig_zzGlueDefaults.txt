# LoreRim Glue - gap filler. This is a NEW file; it overrides nothing.
#
# WHY IT EXISTS
# CBPC merges every Data\SKSE\Plugins\CBPConfig*.txt in the VFS. 3BA's winning CBPConfig.txt is
# 13 bytes long ("Tuning.rate 0") and replaces CBPC's 6272-byte default, which was the only file
# that defined the aliases "Breast", "Butt" and "Belly". After the merge:
#   Breast  -> only .amplitude existed  (CBPConfig_BreastAmplitude.txt)
#   Butt    -> only .amplitude existed  (CBPConfig_ButtAmplitude.txt) - filled here pt8..pt18,
#              since pt19 fully defined in CBPConfig_butt.txt instead (see below)
#   HDTBelly-> nothing at all
# while the two ConfigMaps still both claim the same four nodes:
#   CBPC   CBPCMasterConfig.txt      NPC L/R Breast=Breast   NPC L/R Butt=Butt   HDT Belly=Belly
#   3BA    CBPCMasterConfig_3BA.txt  NPC L/R Breast=LBreast  NPC L/R Butt=LButt  HDT Belly=HDTBelly
# Whichever duplicate CBPC keeps, one of those bone/alias pairs ends up with no stiffness, no
# damping and no offsets. This file fills only the gaps, so the result is the same either way.
#
# It defines ONLY aliases that nothing else in the merged config defines:
#   Breast.*   - copied verbatim from CBPC's own CBPConfig.txt
#   HDTBelly.* - copied from 3BA's CBPConfig_belly.txt Belly.* values
# Butt.* is NOT here any more (pt19, 2026-09-24). From pt8 to pt18 this file carried CBPC's default
# Butt block (stiffness 0.03, damping 0.05, +-2.44, timetick 13.33, timeStep 0.40), which - under
# the alias CBPC's own master config binds - kept the butt in the same stiff, sub-visible class as
# 3BA's Elastic preset (ceiling 2.44 x the 0.204 skin weight = 0.50 units at the best vertex). All
# three butt aliases (LButt, RButt, Butt) now live together in CBPConfig_butt.txt at 3BA's "Very
# Soft" values, so no key of the Butt alias is defined in two files: cbp.dll recognises both the
# legacy "stiffness" and the per-axis "stiffnessX" spellings, and which file wins when two define
# one alias is undocumented.
# It deliberately does NOT define LBreast/RBreast/LButt/RButt/ExtraBreast*/Belly/leg aliases -
# those are fully tuned by 3BA (or, for the butt, by CBPConfig_butt.txt) and must keep those values.
# It deliberately does NOT define any .amplitude - those live in the three amplitude files next
# to this one, so there is exactly one place per alias where the master volume is set.
# The "zz" in the filename makes it sort last, so it can never shadow a tuned 3BA value.
